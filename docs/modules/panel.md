# Панель

## Назначение

Сайдбар Project Web Pilot для браузера. Одна страница расширения `panel.html` для всех браузеров.

## Хозяева отображения

| Хозяин | Браузеры | Ширина и сторона | Открытие |
| --- | --- | --- | --- |
| `chrome.sidePanel` | Chrome 114+, Edge | Ширину тянет пользователь; сторону слева/справа задаёт настройка браузера | Только по действию пользователя (кнопка расширения, сочетание клавиш) |
| `sidebar_action` | Firefox (десктоп) | Ширину тянет пользователь; по умолчанию слева | По действию пользователя |
| iframe в странице | Safari (macOS, iPadOS, iOS), Firefox Android | Своя ручка изменения ширины; ширина запоминается в `storage.local` | Автоматически на странице провайдера |

Встроенный режим (iframe; если страница не загрузила iframe за 5 с — запасная отрисовка прямо на странице, D14):

- **iPad и Safari на Mac:** «сдвиг» — содержимое страницы провайдера уходит вправо на ширину панели. Если сдвиг ломает вёрстку — «поверх» (решает этап 0, Q3).
- **iPhone:** выдвижная панель поверх страницы; в свёрнутом виде — тонкая полоска прогресса, например «T003/7 · работает».

## Содержимое

Как в сайдбаре Electron, без служебных экранов:

- проекты (только активные) с раскрытием;
- сессии проекта: название, Chat/Work, время создания; открыть, переименовать;
- «Новая сессия» с выбором Chat/Work;
- карточка плана: scope, выполнено/всего, текущая задача, состояние (работает, ждёт приёмки, заблокирован, нет плана), ревизия и время последнего успешного чтения;
- индикатор агента и таймер;
- состояние связи: «Mac недоступен», «данные устарели», «нужно подключить устройство».

Не входят: удаление и архивирование проектов, настройки Web Pilot, Доктор, управление рантаймом и туннелем.

## Обновление данных

- Состояние проектов — по действиям и раз в 15 с, пока панель видима.
- План выбранного проекта — раз в 5 с, пока панель видима.
- Пауза, когда панель скрыта; растущая задержка после ошибок; свежее чтение при возврате.
- События сервера (SSE) — позже, если опроса окажется мало.

## Переиспользование

Разметка и стили — по мотивам `src/ui/sidebar.mjs` и `src/ui/index.html` Web Pilot. Вместо IPC Electron — сообщения фоновому скрипту.

## Безопасность

- Страница расширения — отдельный origin; скрипты страницы провайдера её не читают.
- Токен устройства в панель не передаётся: запросы делает фоновый скрипт.
- Сообщения принимаются только от контекстов своего расширения.
