# Web Pilot Sidebar

## Назначение

Работать со своими проектами из любого браузера и устройства так же, как в Project Web Pilot: слева сайдбар workflow, справа настоящая страница провайдера. Без отдельных приложений под каждое устройство и без второй копии проектов.

## Пользователь и сценарии

Один пользователь — владелец Project Web Pilot — на своих устройствах.

1. На iPad в Safari открыть chatgpt.com. Слева видны проекты и прогресс плана. Выбрать проект и начать новую сессию: пакет восстановления вставляется и отправляется, сессия появляется в сайдбаре и в Web Pilot на Mac.
2. Открыть сохранённую сессию проекта — переход в её чат.
3. Следить за прогрессом todo-plan и состоянием агента во время работы.
4. То же в Chrome, Edge или Firefox на любом компьютере.
5. Позже: то же для claude.ai; создание проекта из сайдбара.

## Платформы

| Браузер | Где сайдбар |
| --- | --- |
| Chrome / Edge (десктоп) | Встроенная боковая панель браузера (sidePanel); сторону слева/справа задаёт настройка Chrome |
| Firefox (десктоп) | Встроенная боковая панель (sidebar) |
| Safari на macOS, iPadOS, iOS | Панель, встроенная в страницу |
| Firefox на Android | Панель, встроенная в страницу |

## Границы

- Хост — Project Web Pilot на Mac. Без него расширение показывает «Mac недоступен».
- Расширение не хранит проекты и планы, не пишет в репозитории, не удаляет и не архивирует проекты.
- Ответы чата не выгружаются: только вставка, отправка, наблюдение состояния, адрес и заголовок чата.
- Сборка, проверка интерфейсов и Computer Use остаются на Mac.
- Распространение — только на свои устройства: Chrome/Edge в режиме разработчика, Firefox через неопубликованную подпись, Safari через Xcode или TestFlight.

## Критерий успеха

На iPad в Safari новая сессия в выбранном проекте начинается одним действием, видна в Web Pilot на Mac, прогресс плана обновляется во время работы агента. И это ощущается как Web Pilot, а не как обходной путь.

## Запасной вариант без кода

Split View в Chrome 145+, Firefox, Edge или два окна Safari на iPad: вкладка с сайдбаром рядом с вкладкой chatgpt.com. Мост к чату в этом случае только через MCP-инструмент `session_start` на стороне Web Pilot.
