Web Pilot Sidebar

Включите расширение: Настройки → Приложения → Safari → Расширения → Web Pilot Sidebar. Затем откройте chatgpt.com в Safari и разрешите расширению доступ к сайту.

Включите Web Pilot Sidebar в настройках Safari, раздел «Расширения».

Расширение включено. Откройте chatgpt.com в Safari: панель появится слева.

Расширение выключено. Включите его в настройках Safari, раздел «Расширения», и разрешите доступ к chatgpt.com.

Адрес и код подключения покажет помощник Web Pilot на Mac.
